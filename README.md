**Windows 98 HTML Clone**

A visual and partially functional clone of Windows 98 interface built with HTML, CSS, and JavaScript. Created as a fun experiment to see if AI could replicate a classic operating system UI.

**Features**
- Authentic Windows 98 visual styling (3D borders, classic color scheme, pixel-perfect icons)
- Interactive Start Menu with classic layout
- Draggable "My Computer" window with title bar, toolbar, address bar, and status bar
- Desktop icons with selection states
- System tray with live clock
- Startup sound and boot overlay

**Tech Stack**
- HTML5
- CSS3 (custom properties for Win98 color palette)
- Vanilla JavaScript

**AI Disclosure**
This project was primarily generated by AI (Gemini) as an experiment. Manual adjustments and testing were done by me.
